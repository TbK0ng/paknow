# AI 评价

> 本章是一份**AI 自评**：由参与实现的大模型撰写的诚实评估。它没有人工金标准支撑，分数是主观判断，但每条结论都尽量绑定可核验的证据（计数、实测输出、代码位置）。请把它当作"第二双眼睛"，而不是验收报告。

## 1. 它是什么 / 不是什么

**是**：一个围绕**可追溯证据**构建的本地资料 RAG 系统，带条件主张图谱、派生视觉索引与可版本化的程序性记忆。

**不是**：

- 不是通用问答机器人（资料之外没有知识）；
- 不是图像检索系统（视觉是"观察文本代理"，不是 image-to-image）；
- 不是交易建议系统（明确拒绝无依据的胜率/预测）；
- 不是已完成评测的系统（人工评测与回测搁置）。

## 2. 值得肯定的部分

| 优点 | 证据 |
|---|---|
| **引用可追溯** | 每个 `[n]` 绑定 `evidence_id`，最终渲染到书/章/图/页；越界索引被丢弃 |
| **数据审计扎实** | 实测计数据暴露了多项"看起来有、实际没有"：父块悬空 743/743、邻接 0 条、图注链接 0 条、观察污染 725 条 |
| **派生材料边界清晰** | `quality=derived_observation` + 生成端独立"图读辅助"块，引用体系不被污染 |
| **条件化知识** | 主张带 `qualifiers.context/modality`，检索按条件排序 |
| **记忆有生命周期** | `observed → … → active`，git 每次变更可 diff；自动闭环只到 `shadow` |
| **失败隔离与降级** | 每条召回路径独立 `try/except`；核验器失败 fail-open；重排失败回退 RRF |
| **分析优先** | `wants_examples` 分流；理解类问题不罗列图例；图例目录禁止编造 |

## 3. 必须承认的短板

| 短板 | 影响 | 现状 |
|---|---|---|
| **没有人工作为金标准的评测** | 无法证明"效果更好"，也无法比较 SOP | 已搁置（用户决策） |
| **SOP `active` 门槛关闭** | 记忆优化只完成一半；候选方法可能无效 | 依赖评测集 |
| **端到端延迟 20–60s** | 交互体验一般 | 云端生成占大头；并行化未做 |
| **视觉能力有边界** | 不能做图像相似检索；观察文本可能漏细节 | 已在文档与提示词中标注 |
| **图谱质量不均** | 主张来自图注/标题的 LLM 抽取，置信度未回放验证 | `extraction_confidence` 已留字段 |
| **SQLite 并发写** | 后台优化线程与查询并发时可能抖动 | 未开 WAL |
| **可复现性受限** | 资料有版权不入库；模型缓存依赖本机 GPU | 文档给出完整流程 |
| **自动触发阈值（20）未经调优** | 可能过早/过晚触发蒸馏 | 经验值 |

| 维度 | 分数 | 理由 |
|---|---:|---|
| 架构与边界 | 9 | 分工清晰；明确不做什么 |
| 数据审计与溯源 | 9 | 定位字段完整；用计数验证设计 |
| 检索工程 | 8 | 多路召回 + 重排 + 多样性 + 降级；toc/图谱已接线 |
| 查询构建 | 8 | 单次计划稳定；改写优先级正确；词边界与消歧到位 |
| 多模态 | 7 | 观察式可用且有边界标注；非真正的跨模态检索 |
| 生成与引用 | 8 | 引用可靠；分析优先；图例策略闭环 |
| 记忆体系 | 8 | 设计与版本化强；active 门槛未通 |
| 工程化 | 8 | 接口/存储可迁移；并发与延迟待优化 |

| **效果验证** | **3** | **无人工评测/消融；这是最弱项** |

> 综合印象分约 **7.5/10**：作为"可追溯、可审计的领域 RAG 工程样板"是高质量的；作为"已被证明效果最优的系统"还不成立。

## 5. 如果继续做，最值得的三件事

1. **冻结一个小评测集（30–50 题）**：定义题 / 规则题 / 框架题 / 指代题各若干，人工标注"可接受答案"。它一到位，SOP 回放与消融实验立刻可做。
2. **开 SOP 对照回放**：让候选 SOP 与基线在同一评测集上跑，按胜/负/平记录；这会自动激活 `active` 晋升。
3. **延迟优化**：路由与核验并行、简单问题跳过重排、生成流式化。把 20–60s 压到 10s 量级，交互体验会有质变。

## 6. 一句话结论

> 这是一套**知道自己不知道什么**的 RAG 系统：证据可追溯、派生材料有边界、记忆有版本、失败有记录；它缺的不是更多功能，而是一次真正的人工验证。
