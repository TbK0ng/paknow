# 派生观察不得作为可引用证据

视觉模型对页面与图生成的描述文本（`derived_observation`）只作为索引与召回材料进入检索，生成答案时被移出可引用证据集，单独放进“图读辅助”块。理由是派生文本会以原文的语气复述内容，一旦参与引用，读者无法分辨哪一句出自作者、哪一句出自模型；代价是同一条内容要维护“可引用 / 仅辅助”两条通路，且模型描述不能作为出处被点名。

## 影响

- 引用只允许指向原文证据；派生观察进入答案时必须显式标注为辅助材料。
- 观察文本与原文证据共用索引，但不得共用引用权限；清理污染的脚本（`scripts/fix_observations.py`）属于常态运维，不是一次性迁移。
- 引用体系的可信度优先于召回率：宁可少给一条出处，不可给出模型编造的出处。
