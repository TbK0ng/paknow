# PA Agent：从原文到候选复核

PA 只提名；PAknow 只复核用户明确发起的候选（单笔或确认批量）。单笔可以先在页面预览图谱规划和原文，不调用模型；明确复核时才把同一份证据包送给模型。背景、区间位置和PA 二次测试的性质影响**要查什么**，不新增入场门槛。图书是静态原则，不证明当前行情已经发生。通过才会挂出条件式模拟方案，后续由程序逐根执行。

## 当前链路

1. **六份原件、纯文本、父子段落。** 在同页／同 EPUB 文档项、同章节和同一出处类型内，将邻近 PDF 碎块及紧邻的条件／例外合并。英文和中文句界保留限定语；超过普通检索长度的相邻例外仍与主张同属一个阅读父段；较长段落保留父块和子块的字符偏移。EPUB 的节路径按文档内的目录锚点更新。父块只供展开；完整的短段不硬拆。原始子片段保留精确出处和 ID，可作为核验过的图谱锚点，不重复进向量库。只含图号的块不索引；作者图注、页码、EPUB 锚点保留，不提取或存储位图。
2. **信号时间的特征。** 前 80 根收盘 K 线与信号单独输入。程序标记背景、区间边缘与障碍、曾越界又收回、规则二次测试与 EMA 代理，以及信号是否已收过前一根极值。较严格的重复探测还检查两个不同探测点及中间反应，仍只是描述。不会把信号棒当成后续跟进。
3. **图谱先规划三类问题。** 按形态 × 背景 × 失效条件，沿经过原文校验的概念 → 条件问题 → 原文边找支持、反证和确认线索。不从目录或标题自动推断取证关系。同一角色的图谱问题和按当前行情生成的补充问题都会实际检索；每段候选按召回它的问题重排。图谱直接找到的原文也参与重排，但没有自己的 RRF 分数。信号触边、收在边线上、或收在外侧都不等于越界后收回区间内；只有后者查询相应失效关系。反证按不同失效机制分配问题，避免两条近似的假突破问题挤掉 EMA 代理或边界障碍；区间反转的背景问题与有实际两次探测及中间反应的问题可同时保留。逆势多和逆势空各有独立的条件原文。
4. **按角色选证。** 只以原文／OCR 为证据。先分配能同时覆盖最多角色的独立原文，再补另一项适用风险或文本线索，总计最多五段。同父段子块或重复原文不能算两份独立证据。「已核验」只证明原文和取证关系，不表示本例已满足其条件；文本线索不冒充已核验角色；图谱无匹配或不可用时继续显示文本，同时明示缺口，缺关键证据或无法验证必要父段上下文时不发付费复核、不写判定；辅助召回或重排降级但三类独立原文均已核验时，保留证据并显示提示。页面可查看实际检索问题、原文适用限制和父段原文。
5. **区分原文、事实、方案。** 正方、反方、下一步各需引用其角色里的逐字连续片段；服务器核对片段、出处、角色及独立性。行情引用和方案的实际非空价位要能指回这 81 根的某个时间与 OHLC 字段；程序计算真实参照价及其与方案的差值。只能同向，执行只看结构化方案，不把解释文字当成订单。如果模型判断还需要后续触发或收盘确认，方案必须使用对应的触发方式；收盘确认型的入场有效期至少两根。无法表达的必要条件不能挂单。校验能证明文本和价格锚点存在，不能证明模型对原文解读必然正确。

## 代次与验证

图谱只覆盖已策展的条件，不是书库知识的全集。例如，已有空头下沿障碍的专门原文线索；多头的同类障碍仍纳入文本问题，不能凭镜像方向把它标成一条已核验的图谱边。

- `pa-corpus.json` 绑定六份原件 SHA-256、构建与切块版本、原文和定位/父子关系摘要、图谱配置，以及经核验的主张与图谱边（含关系方向与审核状态）的摘要及 BM25 代次；建库时逐点核对 SQLite 的证据、原文与搜索文本。复核指纹包含此代次；账本只复用与现有语料、规则和复核策略相容的判定。
- `scripts/eval_pa_packet.py` 在同一冻结真实 OKX 窗口对比文本回退与图谱规划，核对实际证据包的原文跨度、父段独立性、缺口和每个取证模式的总耗时（`lookup_ms`）；不调云模型、不生成交易。未标注的文本不能用自动槽位数直接和策展的图谱比优劣。后续评测优先标注独立样例的条件、反证与确认，尤其是未收录的反例和不同趋势背景。
- 保留 BGE-M3、BM25、RRF、交叉编码器与现用复核模型作为基线。调用成本和概率校准需要在**同一份证据包**做实际对照；代码测试、索引覆盖和回放盈亏都不证明模型或 RAG 最优。
