    已完成与待补充¶

    这一页只写两件事：现在有什么（能验证）、还差什么（按能否解锁其他能力排序）。 数据来自本地库快照 2026-10-24；评测口径与产物位置见 评测。

    1. 已完成¶

    模块 完成内容 验证方式
    摄入 EPUB 原生 + PyMuPDF；7 份资料（4 PDF + 3 EPUB）→ 91,978 证据单元、927 图资产 数据库计数
    解析细节 物理页 / 印刷页 / 章节路径 / 图号 / bbox 分别存储；页脚 9,426 条不索引 计数 + 页面抽查
    分块 子块 600–1200 字符；阅读顺序邻接覆盖 91,978 条（100%），父块 743 个入库但不建索引 计数
    索引 BGE-M3 dense + 自研 TF 稀疏；Qdrant 命名向量；81,809 点 计数 + 检索实测
    混合检索 RRF 融合 → 按召回查询打分的 cross-encoder 重排（池 80）→ 多样性（200 字近重复 + 每书 8 条）→ 邻接扩展 单元测试 + 消融
    专用召回 toc 章节框架、图谱扩展、BarRef、caption 定向召回 四路独立开关 单元测试
    查询构建 QueryPlan 单次结构化调用；多轮对话的独立问题改写（history，最近 8 轮） 路由输出 + API 测试
    双语词典 55 个手工概念 + 178 个标题对齐 auto_*，去重后 233 个概念（terms.yaml 236 条词条）；词边界匹配；BTC/AI 消歧 单元测试
    图谱 178 概念节点 + 927 图节点、3,753 边（含 1,888 主张边与 328 标题语法边）；有界 1/2 跳 计数 + 图谱回归
    视觉 927 图全部有 VLM 观察；derived_observation 标记；污染清除（725 条） 计数
    图文链接 几何候选 2,244、标签命中 80、图号回填 276（三种口径，不可相加）；结果 3,779 个单元带 figure_ids（含 56 个父块），共 3,909 条 id，覆盖 927 张图 data/link_log.txt + 计数
    BarRef 674 条结构化指代；强指代零遗漏 计数 + 检索实测
    生成 extractive / synthesis / chart 三种模式；引用后端绑定；派生材料不可引用 三类问题回归
    结构化读图 类型化 ChartRead、单次调用、条带、非图表契约、读图子查询 单测 + 图表评测
    评测 3 个冻结数据集（20/60/10）、4 个 harness、盲评、宽度消融 见 评测
    质量门禁 scripts/quality_gate.py 两档（确定性 / 追加盲评）；10 题分层抽样；硬约束退非零；基线入库 本地实跑 + 单测
    记忆 RunTrace（含版本快照）；SOP 生命周期；git 版本管理；评价→蒸馏→发布到 shadow 端到端闭环
    服务 FastAPI 12 个路由 + 单页查看器 + PDF 页渲染 + 截点遮罩；启动自检（存储缺失/被占用/空库拒启）、/query 可选 debug 块 接口实测
    集成 MCP 适配器（11 个工具，走 HTTP，不依赖内部包） 独立进程实测
    文档 本技术文档站 mkdocs build
    交付 文档站 CI 自动发布；MCP 适配器五道门禁 + SHA256SUMS + git_commit；组件指纹写入每条 trace 见 上线与交付

    2. 待补充¶

    排序标准：能否解锁其他已验证能力。P1 不做，后面的收益都不可证实。

    P1：让"已验证"变成"可持续验证"¶

    事项 为什么重要 现状
    SOP 对照回放 没有回放证据，SOP 永远停在 shadow，记忆闭环是断的 record_replay 有接口，无数据、无 harness
    SOP 五个操作接线 step_back / multi_query / hyde / expand_figures / rerank 只写状态，主链路从不读取；stop 同理 见第 7 章操作表
    把门禁搬进 CI 门禁已在本地覆盖生产链（scripts/quality_gate.py，10 题分层、硬约束退非零、软指标按噪声地板、基线入库），但 CI 只跑确定性单测，变差不会自动红 需要一台能跑索引与模型的 runner；CI 侧已有 tests/test_quality_gate.py 与 tests/test_eval_artifacts.py
    图表金标准人工确认 10 题已全量跑完（漏读 1.8%、多读 8.0%、漂移 0），但 expected_levels 是一次模型初读：三个率可作回归，不能当绝对精度 需要人工逐页核对金标准价位
    机制题覆盖 20 道机制题覆盖率 ≈0：沿边扩展补得了概念，补不了论证链 已定位，未设计
    SOP 指纹失效的可观测性 指纹不符的 SOP 被 select_sop 静默跳过，不写日志、不写 trace——记忆失效没有任何信号 见 上线与交付 §9.2；要改的是跳过分支，不是 yaml

    P2：效果与鲁棒性¶

    事项 说明
    链路损耗 并集探针 73/123 vs 生产 63/123，10 条证据消失在重排/多样性/截断里
    条件短语的检索变体 证据侧目前靠重排与原文自然覆盖，未生成条件子查询
    BarRef pattern → 词典 canonical 纯形态查询（"哪些图有双底"）仍不命中 BarRef
    visual_page / numeric 空路由 QueryPlan 会输出，主链路不消费——要么接线，要么删
    QueryPlan.metadata 字段存在，未接到 Qdrant filter
    观察单元的使用边界 对"图里有什么"合理；对定义类问题只应作辅助，需继续验证
    图表条带重叠 跨条带的结构可能被读成两个

    P3：工程与体验¶

    事项 说明
    延迟与流式输出 单轮 20–60 s；无流式、无查询缓存
    索引参数 81,809 点已超嵌入式 Qdrant 的 20,000 点建议值约 4 倍；HNSW/量化未基准
    SQLite WAL 后台优化线程与查询并发时的写锁抖动
    OCR 接线 当前 0 页需要；扫描版 PDF 才有用
    pabook 元数据 PDF 无 title/author，需手工补
    多用户 / 权限 当前单用户本地系统；服务端零鉴权，streamable-http 只能绑回环（上线与交付 §8）
    成本口径 run_traces.cost_usd 列存在，641 条 trace 全为 NULL：没有用量回传，成本只能按 token 预算估
    指标聚合 指标定义与 SQL 已就绪，但无 /metrics、无看板；elapsed_ms 只存不聚合
    版本可识别性 /health 不返回版本，MCP 客户端的 server_version 恒为 None；版本号三处硬编码、无 tag
    服务产物 无 Dockerfile、无镜像、无部署清单——服务层无法回滚到上一版，只能 git 回退后重建

    3. 明确"不做"¶

    • 回测 / 行情统计：缺少可信数据源与规则定义。
    • 让模型自评当裁判：盲评只产出诊断分，不参与晋升判定（见 评测 §5）。
    • 把派生材料提升为权威证据：视觉观察、图谱主张、读图结果都不能替代原文引用，即使能提高召回。
    • 无数据支撑的数值推断：读图看不清就是 null；没有行情数据就不进 numeric。

    4. 一句话状态¶

    问答链路闭环且可审计；评测已能区分"有没有用"，并有本地质量门禁（CI 只守确定性记录）；记忆闭环停在 shadow， 卡住它的是 SOP 回放，不是模型能力。
