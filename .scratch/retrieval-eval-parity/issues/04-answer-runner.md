# 04: 答案级跑批（两条臂、独立上下文、可续跑）

**What to build:** 对 60 题在独立上下文里各跑一次完整生产链路，图谱开与图谱关两条臂；逐题落盘答案、引用 id、可引用集合、路由、轮数与失败列表；先跑确定性引用硬约束；支持 `--limit` 与 `--resume`。

**Blocked by:** 01, 03

**Status:** claimed

- [ ] `run_query` 透传图谱开关，两条臂除该开关外参数一致
- [ ] 每题一次无状态调用，生成侧看不到期望证据与答案要点
- [ ] 逐题产物含答案、引用 id、可引用集合、路由、轮数、`failures`
- [ ] 确定性硬约束逐题计算：引用 id 必须在自身可引用集合内、不得出现图谱 id、期望证据覆盖率
- [ ] `--limit` 限量、`--resume` 按题目与臂续跑；单题失败记录后继续
- [ ] 单测用替身覆盖透传、checkpoint 合并与三类硬约束，不打真实模型
- [ ] 参考文档记录两条臂与复现命令
