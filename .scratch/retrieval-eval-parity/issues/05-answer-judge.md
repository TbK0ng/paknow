# 05: 答案判定器（盲判、硬约束优先、分层聚合）

**What to build:** 对答案跑批的逐题产物做判定：硬约束失败直接判负；其余由一次盲判模型调用按「结论正确、条件保留、引用支撑」评分并列出不支持断言；按层与按臂聚合，逐题保留。

**Blocked by:** 04

**Status:** needs-triage

- [ ] 判定输入只含题面、期望答案要点、答案与引用证据文本；不含臂名、召回模式或失败列表
- [ ] 输出三段评分与不支持断言，严格解析，缺字段即失败
- [ ] 硬约束失败直接判负，模型评分只做排序与诊断，不合并成单一分数
- [ ] 按层、按臂聚合硬约束通过率与评分分布，逐题结果保留
- [ ] 上线前人工抽查 10 条；判定为通过但引用明显不支撑的，先修判定再跑全量
- [ ] 判定器用替身测试：消息不含分组信息、缺字段失败、硬约束优先级
