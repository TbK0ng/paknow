# 01: 召回生产等价基线、净增益与证据预算

**What to build:** 金标准评测能跑一条与线上文本通道同构的路径（只关闭图谱扩展）；图谱模式同时给出相对并集探针与生产等价基线的差值，净增益以后者为准；图谱证据预算按实测定为 14，召回主指标改为 graph-only 命中数。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] `--mode text` 走同一检索缝、图谱关闭；逐题文本命中 id 与 `--mode graph` 的文本命中相同
- [x] 图谱关闭时不发起种子查询、图谱证据为空、统计明确标记关闭、`failures` 为空
- [x] 图谱模式同时输出相对并集探针与生产等价基线的差值；净增益 = 图谱模式命中 − 文本模式命中
- [x] `MAX_EVIDENCE=14`；`MAX_CONTEXT_TOKENS` 1,200 与 `MAX_EDGES` 32 不变
- [x] 召回主指标为 graph-only 命中数；截断标记继续输出但不作判据
- [x] 并集探针产物逐字节不变；生产等价基线独立落盘
- [x] 单测覆盖图谱关闭的分区行为、净增益算术、预算默认值
- [x] 参考文档记录三种召回模式与复现命令
