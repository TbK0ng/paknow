# 图谱扩展：把概念分类与主张边接进召回

## Problem Statement

用户用组合式问法提问时召回对不上。百科（占语料 72%）的条目名是「情境：形态 + 结果」的结构，例如「开盘跳空高开 + 三角形：多头突破失败」；用户换一种说法问「高开后三角形没突破成，后面常见什么」，文本混合召回只能匹配到「三角形」这类共享词，拿不到对应条目，更拿不到它的变体与失效情形。

跨书机制问题同样如此：Al Brooks 三本讲的是「趋势 → 交易区间 → 反转」的机制链，答案需要把散落在不同书、不同章节的带条件主张串起来，而当前召回只是一批互不相邻的段落。

同时，系统里已经有的概念、主张、图挂载没有被用于扩展召回；图谱上下文以整块 JSON 塞进提示词，既占预算，又不能回指到可引用的原文证据。

## Solution

召回之后增加一次**图谱扩展**：以查询词命中的概念与已召回证据里的概念为种子，沿概念分类（`PART_OF` / `EXCEPTION_TO` / `INVALIDATED_BY` / `TRANSITIONS_TO`）与主张边回取证据单元，与文本证据分区进入提示词。

- 图谱扩展**不参与打分与融合**，排序仍由文本通道决定（见 ADR-0003）。
- 图谱推出的结论**不可引用**，只作理解辅助；引用仍指向原文证据（见 ADR-0002）。
- 概念分类的边由百科标题语法确定性地解析而来；主张边由既有主张表转换而来。
- 先用 20 条金标准证明「图独有」的增量，再接线。

## User Stories

1. As a 价格行为学习者, I want 组合式问题（情境 + 形态 + 结果）召回到百科对应条目及其上下文, so that 我不用猜中作者的命名方式才能查到这个形态。
2. As a 价格行为学习者, I want 问「双底失败有哪些变体」时看到同一概念分类下的兄弟条目与失效情形, so that 我能一次看清一个形态的全家族。
3. As a 价格行为学习者, I want 问机制类问题时拿到跨三本书的机制链证据, so that 我得到的不是单本书里的零散段落。
4. As a 价格行为学习者, I want 图谱归纳的内容与作者原话在答案里分开呈现, so that 我能分清哪句可以核对出处。
5. As a 价格行为学习者, I want 图谱结论不被当作引用来源, so that 我不会把一个待核验的抽取结果当成作者原话。
6. As a 价格行为学习者, I want 问「书里有没有说过 X、在什么条件下」时拿到带条件的主张, so that 我拿到的是条件化断言而不是绝对结论。
7. As a 价格行为学习者, I want 图谱扩展召回到的证据仍带原始定位（章节、图号、页）, so that 我能回到书里核对。
8. As a 维护者, I want 标题解析是确定性的、可重复的, so that 同一份语料重跑得到同一批边。
9. As a 维护者, I want 每条边记录来源（标题解析 / 主张抽取 / 人工种子）, so that 我能按来源关停或重建而不影响其他边。
10. As a 维护者, I want 解析不出的标题被丢弃并输出覆盖率, so that 系统不会为了「看起来完整」而猜一个关系。
11. As a 维护者, I want 页眉式重复标题在解析前被剔除, so that 一万条噪音不会污染概念分类。
12. As a 维护者, I want 图谱扩展在缺口轮只为新出现的概念增量补跑, so that 补检索不会反复展开同一批边。
13. As a 维护者, I want 图谱扩展失败时回答继续（fail-open）并在运行轨迹里留下原因, so that 一次边查询失败不会让整个问答挂掉。
14. As a 维护者, I want 图谱扩展不改变文本通道的排序, so that 效果归因时能分清是哪条路径带来的证据。
15. As a 评测者, I want 20 条金标准问题各自记录期望证据与期望关系, so that 我能判定每条问题是否「图独有」。
16. As a 评测者, I want 「图独有」的口径与线上召回宽度一致（6 条扩展查询的 top-20 并集）, so that 评测结论能外推到线上。
17. As an MCP 客户端, I want 答案里的引用编号仍然只对应可引用证据, so that 我展示给用户的出处不会指向图谱归纳。
18. As a 用户, I want 新增源文档后概念分类可以重建且不影响人工种子, so that 语料增长不需要重做人工工作。

## Implementation Decisions

**概念分类的边**

- 解析对象是百科的标题类证据单元，先按「同文档内归一化文本完全相同留首次、出现次数 ≥5 视为页眉丢弃」去重；当前 16,644 条标题中 10,295 条属于此类重复，去重后约 6,349 条。
- 标题语法：以「：」切出情境与条目；`失败` 映射 `INVALIDATED_BY`，`随后` 映射 `TRANSITIONS_TO`，`但…恢复/继续` 与 `例外` 映射 `EXCEPTION_TO`，其余落入 `PART_OF` 的只有能识别出明确上级概念的条目；识别不出的丢弃，不兜底。
- 不新增关系类型，复用现有 `Relation` 枚举。
- 每条边写 `source`，取值区分 `heading_parse` / `claim_extract` / `seed`；`extraction_status` 沿用 `pending`。
- 开头约 10 页的目录表格只用于校验解析覆盖率（人工抽查），不参与主抽取。

**主张边**

- 现有 1,888 条主张中只有 278 条挂了规范概念。先做确定性对齐（词典别名 + 主体规范化），残差再走批量模型并带置信度阈值；评测前不做人工复核。
- 主张边只用于扩展与理解辅助，不进入可引用集合。

**图谱扩展**

- 种子两支并发：查询词经词典命中的概念先发，与文本召回并发；文本召回返回后再用命中证据里的概念补一次。
- 展开深度：概念分类 1 跳，机制链 2 跳；预算上限：概念 ≤8、边 ≤32、回取证据 ≤8、图块 ≤1,200 tokens；超限时按「机制链优先于分类树、证据相关性优先于边数量」截断。
- 回取到的证据带 `provenance=graph` 标记；若该证据已在文本结果中，不重复正文，只标「已见 [n]」。
- 只在首轮与「出现新概念」的缺口轮执行；同一概念不重复展开。
- 任何一步失败都记入 `failures` 并继续生成。

**提示词分区**

- 顺序保持：目录框架 → 图谱上下文 → 图读辅助 → 证据。
- 图谱上下文由整块 JSON 改为逐条紧凑行，每条带 `evidence_id`，并显式标注「不可引用、仅作理解辅助」。

**词汇与代码对齐**

- `QueryPlan.routes` 中的 `graph_local` 改名或移出 `routes`，与 `GLOSSARY.md` 的「路由 = 有独立打分的召回通道」一致。

**实施顺序**

1. 20 条金标准 + 基线脚本
2. 标题去重与语法解析，产出概念分类边
3. 主张→概念对齐
4. 图谱扩展接线
5. 金标准回归

## Testing Decisions

- **唯一新缝**：把检索阶段抽成一个可独立调用的入口，返回「文本命中 + 图谱证据 + 分区信息 + 失败列表」，LangGraph 的检索节点退化为薄适配层。所有检索行为断言都打在这条缝上；不在内部函数上调断言，不测调用次数。
- **纯函数直测**：标题去重与标题语法解析接受一批标题、产出一批边，可完全脱离数据库与模型测试；断言边的关系类型、端点、来源标记与丢弃行为。
- **金标准是离线评测**，不是 CI 门禁：20 条问题（百科 10、机制 10），每条记录期望证据与期望关系；用基线脚本跑「6 条扩展查询的 top-20 并集」，未命中至少一条期望证据即记为「图独有」。因为现有 HTTP 检索接口只接受单查询，基线必须走脚本。
- **好测试的标准**：只断言对使用者可见的结果（召回到哪些证据、哪些被标记为不可引用、预算超限后剩下什么），不断言内部实现细节、不断言模型输出文本。
- **先例**：仓库现有的测试只在 MCP 集成层（模拟 HTTP 服务），检索层没有测试；本条缝是提出来的最高可调用点，位于路由之下、提示词之上。

## Out of Scope

- 图像向量检索（`page_visual` 集合仍为空）与百科补图。
- `metadata` 过滤、`visual_page` / `numeric` 两个空路由的接线或删除。
- 把目录 / 图注 / 数值分支也改成并发（本次只并发查库级别的概念命中）。
- 全量评测框架（金标准之外的 RAG Triad、Recall@k 基准）。
- 主张的人工复核与晋升流程。

## Further Notes

- 语料现状：百科 8,659 页、65,535 个证据单元、**0 张图资产**；三本 Brooks 合计 9,175 单元、446 张图；整库 91,235 单元、927 张图。
- 图谱现状：概念节点 139、图节点 927、主张 1,888（仅 278 挂概念）、`SUPPORTED_BY` 1,888、`ILLUSTRATED_BY` 1,529、结构边 `PART_OF` 4 / `TRANSITIONS_TO` 4，其余关系为 0。
- 百科的 `chapter_path` 最多 1 层、EPUB 为空，没有可用的目录树；概念分类必须由标题语法重建。
- 相关决策：ADR-0002（派生观察不可引用）、ADR-0003（图谱为扩展层而非打分通道）。
