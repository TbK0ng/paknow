# 04: 图谱扩展接线

**What to build:** 文本召回不到的组合式问题，答案里能看到由概念分类与主张边补来的证据；这些证据与文本证据分区呈现、不可引用、超预算时按优先级截断，并且不改变文本通道的排序。

**Blocked by:** 01, 02, 03

**Status:** ready-for-agent

- [ ] 种子两支并发：查询词经词典命中的概念先发、与文本召回并发；文本返回后用命中证据里的概念补一次。
- [ ] 展开深度：概念分类 1 跳、机制链 2 跳；上限为概念 ≤8、边 ≤32、回取证据 ≤8、图块 ≤1,200 tokens；超限时机制链优先于分类树、证据相关性优先于边数量。
- [ ] 回取证据带来源标记；已在文本结果中的不重复正文，只标注「已见 [n]」，引用编号与证据的绑定不被破坏。
- [ ] 图谱上下文从整块序列化改为逐条紧凑行，每条带证据标识，并显式标注不可引用、仅作理解辅助。
- [ ] 只在首轮与出现新概念的缺口轮执行；同一概念不重复展开。
- [ ] 任一环节失败都不阻断回答，失败原因写入运行轨迹。
- [ ] `graph_local` 从路由词汇中退出：路由只保留有独立打分的召回通道，图谱扩展单独命名。
- [ ] 用一次实际查询验证：一个文本召回失败的组合式问法，答案上下文中出现图谱证据，且答案的引用只指向原文证据。
