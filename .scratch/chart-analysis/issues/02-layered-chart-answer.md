# 02: 分层答案：全列可读位、收敛建议、资料依据

**What to build:** 图表问题的答案分三层：① 图上可读位全部原样列出（含图上依据与标注原文），不因收敛而删减；② 按固定优先级收敛出 5–8 个「建议关注位」并各给一句理由；③ 资料依据（带引用）与归纳，读图内容永远不挂引用。用户指定排序时按用户的顺序。

**Blocked by:** 01

**Status:** needs-triage

- [ ] 答案第一层的价位条数与 `chart_read.levels` 一致，且顺序遵循用户要求（如价格从高到低）
- [ ] 第二层给出 5–8 个建议关注位，每个都有一句理由，理由体现固定优先级（图上标注 > 前高/前低 > ONH/ONL > 区间边缘/平台 > 均线）
- [ ] 两个价位数值冲突时保留更极端的那个，另一条出现在 `unreadable` 而不是被静默丢弃
- [ ] 均线类指标只说明存在，参数未知时不给具体价位
- [ ] 用户明确要求「只给清单」时，第一层直接输出，第二层不超过一句话
- [ ] 资料依据部分才有 `[n]`，读图部分的结构上不可能出现引用编号
- [ ] 文本知识问答的答案口径与现在逐字一致（不触发分层）
