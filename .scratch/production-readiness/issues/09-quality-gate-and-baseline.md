# 09: 本地质量门禁与入库基线

**What to build:** 一条本地命令在提交前回答"这批改动有没有牺牲答案质量"：默认按四层（百科 / 机制 / 例外 / 条件主张）抽样 10 道题跑确定性档，硬约束失败无条件退非零，软指标按已测噪声地板容差；基线入库，可逐题复核。它不进 CI，CI 只跑门禁的确定性单测。

**Blocked by:** 01, 02, 03

**Status:** needs-triage

- [ ] 门禁有两档：确定性档（不调云模型）与追加盲评档；默认只跑 10 题分层抽样。
- [ ] 硬约束任一条失败即退非零：引用越界、图谱独有证据被引用、答案为空（降级占位按 03 的分类识别，不靠文本长度）。
- [ ] 软指标有明确地板：判定分单维度差 < 0.12、无据主张总数差 < 15 视为未变化；冻结模式下覆盖率容差收紧到 0.03。
- [ ] 基线与当次运行记录一起入库（ADR-0004），只由显式命令重录；基线带数据集哈希，数据集改动会拒绝误用旧基线。
- [ ] 门禁脚本的确定性单测在现有 CI 里跑通：不 import torch、不连库、不调云模型，CI 不新增 job。
- [ ] 用一次真实确定性运行验证退出码：未改动代码对基线为 0；把基线里任一硬指标改坏后为 1。
