# 02: 答案层评测冻结口径

**What to build:** 答案层评测新增冻结查询模式：用金题自带的问题与扩展查询构造查询计划，绕开现场路由，使同一份代码 + 同一份数据集跑两次得到的查询列表、轮数与覆盖率完全一致。运行记录写明计划来源与每题查询列表哈希，从而区分"可比"与"不可比"的两次运行。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 评测命令新增冻结模式开关；开启后每题的查询计划来自金题的问题与扩展查询，其余链路不变。
- [ ] 逐题运行记录带计划来源与查询列表哈希；汇总记录带数据集哈希，数据集或计划被改动时可立刻发现。
- [ ] 两次冻结模式运行：逐题查询列表、轮数、期望覆盖率完全一致；这条契约有可重复执行的检查（不调云模型）。
- [ ] 不开该开关时行为与今天一致，仍记录路由产出的计划。
- [ ] 生成端的降级标记（见 03）在记录里保持可读，便于门禁判定空答案。
