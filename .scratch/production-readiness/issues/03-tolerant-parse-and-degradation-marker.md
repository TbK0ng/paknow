# 03: 结构化输出容错与降级可机读

**What to build:** 模型输出里出现裸换行、制表符，或尾部跟着第二个 JSON 对象时，用户仍然拿到答案（取第一个完整对象）。确实无法解析时，错误带可机读的失败分类与原文片段；答案被降级时，响应与运行轨迹都明确标记，用户看到"本次生成失败、请重试"而不是把占位文字当作答案。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 解析顺序：严格解析 → 容忍控制字符 → 用增量解码取出第一个完整 JSON 对象；三者都失败才报错。
- [ ] 裸换行/制表符可解析；两个连续对象只取第一个，其后内容忽略；先前的严格校验对缺字段仍然报错。
- [ ] 结构性截断仍报错，错误携带失败分类（解析 / 超时 / 无内容）与原文前 120 字。
- [ ] 降级答案在 HTTP 响应与运行轨迹中带 `degraded: true` 与同一分类；答案正文保留"本次生成失败"的可见提示。
- [ ] 占位答案可与真实的短答案区分（凭分类字段，不靠文本长度猜测）。
- [ ] 读图路径已有的失败分类不被改成第二套词汇。
