# 07: 主张条件唯一映射与渲染规则

**What to build:** 主张的条件只有一处读取映射：写入端存的背景与语气在此对齐为渲染所需的条件，渲染只消费这一处输出。有条件的主张把条件与断言写在同一行；没有条件的主张不出现任何条件字样——不兜底成"无条件"，也不编造条件。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 存在单一映射函数：写入端的背景/语气键在此转换，渲染端不再各自去翻不同键名。
- [ ] 有条件的主张：渲染出的那一行同时含该条件文本与主张内容。
- [ ] 无条件的主张：那一行不含条件字样（"无条件"、"通常在"之类的兜底措辞都算失败）。
- [ ] 图谱扩展候选水合里对已停止使用的旧条件键的读取被删除（库中这些键恒为空）。
- [ ] 两个方向各有一个纯函数测试；条件取自库里真实存在的键，不用假造键。
