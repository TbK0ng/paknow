# 06: API 启动自检

**What to build:** 服务启动时确认内嵌向量库可用：集合存在且可计数。存储缺失、被其它进程占用、集合为空三种情况分别给出人能读的原因并拒绝进入服务，避免出现"进程活着但回答永远是空"的半死状态。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 启动自检确认集合存在且可计数；三种失败（缺失 / 被占用 / 集合为空）各有独立、可读的原因，不共用一句泛化报错。
- [ ] 自检不走会静默建集合的初始化路径，否则空库会被掩盖成"正常"。
- [ ] 健康检查的语义明确：未就绪时返回非 ok 并带原因，或服务根本不接受请求——二者择一，不留下"ok 但不可用"。
- [ ] 三种情况都有测试，且不依赖真实向量库、不启动第二进程。
- [ ] 正常存储下现有接口行为与测试不受影响。
