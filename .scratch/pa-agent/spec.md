# PA Agent · PA 规则与 PAknow 证据分析

**Status:** resolved
**Review base:** 69b8f2783050eb18188d431eb18928ec17f20698

## 目标

PA Agent 使用PA 与 PAknow 原文证据。使用真实已收盘行情，显示完整多空检查，不为观望伪造候选，也不执行订单。

## 交付

- 原生 `/pa-agent` 工作区和同源接口，详见 [使用说明](../../docs/pa-agent.md)。
- 公开 OKX 的滚动五天窗口；窗口外的已确认历史用于指标预热和前部信号的背景。15m 与已收 1h 输入都截止在所选收盘。
- 即使观望，也按未过条件从 PAknow 检索；可选模型用核验过的来源解释背景、反证与下一步验证。规则与引文不混同，派生观察不引用，模型失败不影响规则或已核验出处。
- 每个信号先分析其前 80 根（不含信号）的方向、区间和高低点结构；规则方案和 PAknow 检索都使用这个因果背景，未改变PA 触发。
- 只用 PA 形态和方向价格结构生成候选；第二层用 PAknow 原文、前 80 根及信号做独立裁决。只有完成审核且通过的候选才进入模拟，证据不足或失败均不成交。
- 回放按入选候选分别模拟，允许持有期重叠，按之后的 OHLC 判定各自的止盈或止损，也执行方案定义的收盘结构退出和最长持有期。图上盈绿亏红，出场之前不显示结果；回放未走到退出条件时仍显示持有中。
- 保留上游许可、原规则版本与归属。新测试验证公共行情、时间截止、只读接口，以及无效引用时的降级。

## PA Agent 独立工作区

- `/` 直达 `/pa-agent`，提供 PA 取证、只读行情和用户发起的单笔或批量复核。导入和检索回归在离线工具运行。
- 行情快照与复核账本保持独立；浏览和播放不自动复核，只有用户确认才开始批量复核待处理候选。到期或取消的有效方案可跳回原信号，引用在同一页面展开。
- `POST /pa-agent/review` 返回各阶段耗时；缓存结果不占用模型复核名额。
- 从六份原件按带限定语的父子段落全量重建；冻结原件、SQLite 图谱和 BM25 代次之后，运行图谱先规划三类问题、文本共同重排与原文角色校验。
- 新复核要求原文连续摘录、独立证据组和信号时的行情锚点；图谱只服务取证，不改变PA 规则和纸面执行器。
- 同角色全部规划问题参与召回，独立原文分配优先填齐三类角色；分别支持多空逆势、区间内外和信号越界收回。收盘确认型必须留出确认收盘和次根开盘两根有效期。

## 收尾验证

- 现役 `passages-v2` 从六份原件重新建库并成对切换；复核策略 `paknow-paper-plan-v9-context-roles` 按不同失效机制保留反证问题，区间反转背景与重复探测可同时取证。触边或收在边界上不算收回区间内；已核验关系不等于本例条件成立。
- 24 条原文线索与 48 条审核边通过封存，120 组确定性规划与原文回读检查通过；冻结的真实 OKX 候选经本地混合召回和重排后能拿到三类独立原文。切库后检查了健康、480 根行情和引用父段，未改变复核账本。
- 图谱改造时的 135 项测试、scratch 检查和 `git diff --check` 通过。未调用付费模型，未评估检索相关性、图谱覆盖优劣或复核质量。

## 证据工作台

- 候选先按需本地取证，不写判定或尝试；界面区分三类核验、父段校验失败和辅助降级。单笔模型复核明确发起，短期凭据绑定同一证据包、候选指纹和语料代次；输入变化时不使用旧证据，不入账。
- 行情事实和图谱条件独立显示，原文引文可高亮定位，价格锚点在图上标记且不移动回放游标。切换窗口的响应不跨窗口复用，同一窗口回放投影按顺序更新。
- 用当前真实 OKX 候选验证本地预览、原文展开和行情锚点；受控浏览器夹具验证父段缺失禁用复核、准确高亮引文、乱序投影与未来成交不可见。未发送付费请求，未重建语料或改写复核记录。
- 宽屏两栏分别滚动，已成交列表可展开全部，证据详情收起不会丢失。候选复核显示进行中用时和具体失败原因；维持单次尝试和候选完成预算。
- 「已复核候选」统一列出账本已保存的结论。所选记录跳转到对应 K 线并打开原结论；滚出窗口时用真实本地连续行情回放。可核验的 DeepSeek／Terra 保存方案都可进入模拟；同根 K 线去重，不重新取证或调用模型。
- 云模型默认 MuzeAI Responses 的 `gpt-6.1-terra`（`medium`）；可配置模型和思考强度，也可显式切回旧 DeepSeek Chat 配置。新旧复核凭据与账本结果按实际线路、模型和思考档隔离，旧 DeepSeek 哈希保持兼容。
